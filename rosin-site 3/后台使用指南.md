# 可视化后台使用指南(Decap CMS + Netlify)

你现在有了一个网页后台:登录后,**上传图片、改文字、加博客都在网页上点点点完成**,
不用碰代码、不用维护服务器,全程免费。

后台地址(部署后):`https://你的域名/admin/`

---

## 一、它是怎么运作的(读一遍就懂)

```
你在 /admin/ 后台点保存
        ↓
Decap 自动把改动写回 GitHub(你的代码仓库)
        ↓
Netlify 检测到变化,自动重新发布网站
        ↓
约 1 分钟后,网站更新生效
```

你只接触最上面那一步。下面三步全自动。

---

## 二、一次性设置(大约 20 分钟,只做一次)

> 这部分是为了把后台"通上电"。设置完之后,以后就只剩"登录→编辑→保存"。

### 第 1 步:把网站代码放到 GitHub
1. 注册 github.com(免费)。
2. 新建一个仓库(Repository),名字随意,如 `rosin-site`,设为 Public 或 Private 都行。
3. 把这个 `rosin-site` 文件夹里的所有文件上传上去
   (GitHub 网页上 "Add file → Upload files",把文件拖进去即可)。

### 第 2 步:用 Netlify 部署网站
1. 注册 netlify.com,选择 "Log in with GitHub"。
2. 点 "Add new site → Import an existing project → GitHub",选你刚建的仓库。
3. 构建设置全部留空(这是纯静态站,不需要构建命令),直接 Deploy。
4. 部署完成后,你会得到一个 `xxx.netlify.app` 的网址,网站已经在线。

### 第 3 步:打开后台登录功能(关键)
后台登录用 Netlify 自带的 "Identity" 功能,跟着点:
1. Netlify 站点后台 → **Identity** → 点 **Enable Identity**。
2. Identity 页面 → **Registration** 改成 **Invite only**(只有被邀请的人能登录,防止陌生人注册)。
3. Identity 页面 → **Services → Git Gateway** → 点 **Enable Git Gateway**。
4. 回到 Identity 顶部 → **Invite users** → 输入你自己的邮箱 → 发送邀请。
5. 去邮箱收邀请邮件,点链接,设置一个密码。

### 第 4 步:确认分支名
打开 `admin/config.yml`,看 `branch: main` 这行。
- 如果你 GitHub 仓库的主分支叫 `main`(现在绝大多数都是),不用改。
- 如果叫 `master`,把这行改成 `branch: master`。

完成!现在访问 `你的网址/admin/`,用刚才设置的邮箱密码登录,就能进后台了。

## 三、日常使用(以后你只做这些)

打开 `你的域名/admin/` 登录后,左边有 5 个栏目:

### ① 首页素材
- **松香卡片图 / 钢桶卡片图**:点一下就能上传图片,首页产品卡片立刻用上。
- **宣传视频**:
  - 上传自己的视频:先在别处把 mp4 传上来,或填 `assets/你的视频.mp4`
  - 用 YouTube:填 `https://www.youtube.com/embed/视频ID`
  - 留空 = 首页不显示视频区

### ② 产品规格
松香、钢桶各一个。**顶部大图**可上传;**规格参数表**可以:
- 改某行:直接改参数名 / 参数值
- 加一行:点 "Add 一行参数"
- 删一行:点那行旁边的删除
- 排序:拖动

> 小提示:参数值里如果留着 `[ 填写 ]`,网页上会显示成琥珀色,提醒你还没填。

### ③ 关于页图片
"工厂与发货"画廊。点 "Add 一张照片" 上传,想放几张加几张,自动排版。

### ④ 质量页证书
COA、检测报告、证书扫描件。同样点 "Add 一张证书" 上传。

### ⑤ 博客文章
- **加文章**:点 "Add 一篇文章",填标题、网址短名、摘要、正文。
  正文是所见即所得编辑器,空一行分段,工具栏能加小标题/加粗。
- **改文章**:点开任意一篇直接改。
- **删文章**:点那篇旁边的删除。
- **排序**:拖动调整首页显示顺序。

**改完一定要点右上角 "Publish"(发布)**,网站才会更新。约 1 分钟生效。

## 四、连接你自己的域名

1. 买域名(Namecheap / GoDaddy / Cloudflare)。
2. Netlify 站点后台 → **Domain settings → Add a custom domain** → 输入你的域名。
3. Netlify 会给你 DNS 记录,去域名商后台填上(apex 域名加 A 记录,www 加 CNAME)。
4. 等几分钟到几小时生效,Netlify 自动配好免费 HTTPS。

域名生效后,后台地址就变成 `https://你的域名/admin/`。

## 五、常见问题

**Q:后台保存了,网站没变?**
A:确认点了 "Publish",然后等约 1 分钟。Netlify 在重新发布,刷新页面看看。

**Q:图片上传后放在哪?**
A:自动存进 `assets` 文件夹并提交到 GitHub,你不用管。

**Q:能多人用吗?**
A:能。在 Netlify Identity → Invite users 邀请对方邮箱即可,各自有账号。

**Q:我想本地双击 html 预览,但内容空白?**
A:本地直接双击打开时,浏览器出于安全限制无法读取 JSON 文件,属正常现象。
   部署到 Netlify 后一切正常。想本地预览可在文件夹里运行一个简单本地服务器
   (如 VS Code 的 Live Server 插件)。

**Q:不想用后台,能直接改文件吗?**
A:能。内容都在 `content/` 文件夹的 JSON 文件里,可以直接用文本编辑器改,
   或在 GitHub 网页上改。后台只是更直观的入口。

## 六、文件说明(了解即可,平时不用动)

```
admin/
├── index.html      后台入口页
└── config.yml      后台字段配置(定义你能编辑哪些内容)
content/            ← 你的网站内容(后台读写的就是这些)
├── home.json       首页图片/视频
├── product-gum-rosin.json    松香规格
├── product-steel-drums.json  钢桶规格
├── about.json      关于页照片
├── quality.json    质量页证书
└── blog.json       所有博客文章
js/
├── data-loader.js  负责把上面的 JSON 加载到网页(不用改)
├── main.js         渲染逻辑(不用改)
├── config.js       公司名/邮箱/WhatsApp(部署前填一次)
└── content.js      本地预览时的后备内容(可忽略)
```
